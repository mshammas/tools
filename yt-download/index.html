What it does

Three tabs in one window. Nothing is uploaded anywhere — every job runs locally with ffmpeg.

Download

Fetch a video at the highest resolution available. Cap the resolution if you want a smaller file, choose MP4 (H.264 + AAC, plays anywhere) or MKV for 1440p and 4K, and optionally split a long video into one file per chapter.

Clip

Cut a segment out of a local file or straight from a link, giving start and end as HH:MM:SS, MM:SS or plain seconds. Re-encodes for a frame-exact cut, or copies the streams for a near-instant one.

Mix

Join clips one after another with optional crossfades, lay them out side by side in a grid, or blend them on top of each other — useful for comparisons and picture-in-picture.

Before you start

A few things worth knowing — they will save you a confused minute on first launch.

  • ffmpeg and yt-dlp are not bundled The app looks for both on your system when it starts and points you at the right install command for your platform (Homebrew, apt, winget or pip). Everything the app does is built on top of them.
  • The builds are not signed with a developer certificate macOS will refuse the first launch — right-click the app and choose Open, then confirm. It only asks once. On Windows, SmartScreen shows a warning: click More info → Run anyway.
  • Windows: the Download tab needs bash Downloading is driven by a shell script, so it needs WSL or Git Bash installed. The Clip and Mix tabs are pure Python and work without it.
  • Nothing leaves your machine There is no account, no server and no telemetry in the app. Files are read and written only where you tell it to.

Installing

Pick your platform.

  1. Install the two helpers if you do not have them: brew install ffmpeg yt-dlp
  2. Download the .dmg, open it, and drag Video Tools into your Applications folder.
  3. The first time, right-click the app and choose Open, then confirm. macOS asks because the app is not signed with an Apple Developer ID; it only asks once. You can eject the disk image afterwards.
  4. If macOS instead calls the app damaged, you are on an older download — get 1.0.1 above, or clear the quarantine flag on what you have: xattr -dr com.apple.quarantine "/Applications/Video Tools.app"
  1. Install the two helpers if you do not have them: winget install Gyan.FFmpeg yt-dlp.yt-dlp
  2. Download the .zip. Before extracting, right-click it, choose Properties and tick Unblock — otherwise Windows marks everything inside it as came-from-the-internet. Then extract it anywhere; there is no installer to run.
  3. Launch video-tools.exe. If SmartScreen appears, choose More info → Run anyway.
  4. For the Download tab, make sure WSL or Git Bash is installed.
  1. Install the two helpers if you do not have them: sudo apt install ffmpeg pip install --upgrade yt-dlp
  2. Download the .tar.gz and unpack it: tar -xzf video-tools-*-linux.tar.gz
  3. Run the video-tools binary inside. Optionally copy the bundled .desktop file into ~/.local/share/applications/ to get a launcher entry.
