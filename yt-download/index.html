What it does

Three tabs in one window. Nothing is uploaded anywhere — every job runs locally with ffmpeg.

Download

Fetch a video at the highest resolution available. Cap the resolution if you want a smaller file, choose MP4 (H.264 + AAC, plays anywhere) or MKV for 1440p and 4K, and optionally split a long video into one file per chapter. Paste in several links, or a whole playlist, and they download one after another — including the …&list=… link you get by copying the address while a playlist video is playing, which brings in the whole list unless you untick Expand playlists.

Clip

Cut a segment out of a local file or straight from a link, giving start and end as HH:MM:SS, MM:SS or plain seconds. Re-encodes for a frame-exact cut, or copies the streams for a near-instant one.

Mix

Join clips one after another with optional crossfades, lay them out side by side in a grid, or blend them on top of each other — useful for comparisons and picture-in-picture.

Before you start

A few things worth knowing — they will save you a confused minute on first launch.

  • ffmpeg and yt-dlp are not bundled The app checks for both and offers to fetch them for you the first time a tab needs them — through Homebrew, apt, winget or pip where one of those is available, and otherwise by downloading the projects' own prebuilt binaries. Everything the app does is built on top of them.
  • The builds are not signed with a developer certificate macOS blocks the first launch with “Apple could not verify…”. On macOS 15 and later there is no right-click → Open bypass, so the Installing steps below clear the flag on the disk image before you install — one command, or a toggle in System Settings if you have already installed it. On Windows, SmartScreen shows a warning: click More info → Run anyway.
  • Nothing leaves your machine There is no account and no telemetry in the app, and files are read and written only where you tell it to. The one thing it sends is a daily check with GitHub for a newer version, which carries nothing about you and can be switched off under Help → Check for updates automatically.

Installing

Pick your platform.

  1. Optional: install the two helpers yourself. If you skip this, the app offers to fetch them the first time a tab needs them: brew install ffmpeg yt-dlp
  2. The app is not notarised by Apple, so macOS flags the download and blocks the first launch. Clear that flag on the .dmg before you install, and nothing it contains inherits it: xattr -d com.apple.quarantine ~/Downloads/video-tools-*-macos.dmg
  3. Open the .dmg and drag Video Tools onto the Applications folder next to it. It now opens normally. You can eject the disk image afterwards.
  4. Already dragged it across first? Then clear the flag through System Settings instead: try to open the app, click Done, then go to System Settings → Privacy & Security, scroll to Security and click Open Anyway. Running the command above against the copy in /Applications will not work — macOS protects installed apps from being modified, and answers Operation not permitted even under sudo.
  1. Optional: install the two helpers yourself. If you skip this, the app offers to fetch them the first time a tab needs them: winget install Gyan.FFmpeg yt-dlp.yt-dlp
  2. Download the .zip. Before extracting, right-click it, choose Properties and tick Unblock — otherwise Windows marks everything inside it as came-from-the-internet. Then extract it anywhere; there is no installer to run.
  3. Launch video-tools.exe. If SmartScreen appears, choose More info → Run anyway.
  1. Optional: install the two helpers yourself. If you skip this, the app offers to fetch them the first time a tab needs them: sudo apt install ffmpeg pip install --upgrade yt-dlp
  2. Download the .tar.gz and unpack it: tar -xzf video-tools-*-linux.tar.gz
  3. Run the video-tools binary inside. Optionally copy the bundled .desktop file into ~/.local/share/applications/ to get a launcher entry.
